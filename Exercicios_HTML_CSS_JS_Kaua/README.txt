Como abrir:
1. Abra o arquivo index.html desta pasta.
2. Clique em uma das três questões.

Observação:
É necessário estar conectado à internet para carregar o jQuery e as imagens da questão 1.

Para publicar no GitHub Pages:
1. Crie um repositório no GitHub.
2. Envie todo o conteúdo desta pasta para o repositório.
3. Entre em Settings, depois Pages.
4. Em Branch, escolha main e / (root), depois clique em Save.
